# @videofy-live/language-catalogue

PRIVATE data-only catalogue of the ~80 widest-reach languages, keyed by BCP-47
BASE subtag (`en`, `yo`, `fil`), with English/native names, script, direction,
main regions and a reach rank. No vendor knowledge lives here: which engine can
translate a pair is the language-router's business. This package only answers
"what is `yo`?" and "what did the user mean by `français`?".
