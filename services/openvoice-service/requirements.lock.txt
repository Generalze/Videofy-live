# OpenVoice V2 personal-voice service - resolved runtime (P6.3).
#
# Captured from .venv-openvoice-clean: a venv built from nothing, engine
# installed NON-EDITABLY from wheels, PYTHONPATH unset, and the source checkouts
# renamed away to prove the runtime does not need them. That is the environment
# this file describes. The previous lockfile described a venv that was not
# serving requests at all.
#
# DELIBERATELY ABSENT: faster-whisper, ctranslate2, av, whisper-timestamped.
#
# Upstream OpenVoice metadata requires them for its se_extractor/Whisper path,
# which Videofy does not use and never calls. Not assumed from setup.py:
# scripts/openvoice-runtime-graph.py exercises the real path (converter load,
# extract_se, convert, MeloTTS synthesis) and reports which modules were
# actually imported. None of the four appear. Installing them would mean
# compiling an old PyAV from source in order to avoid calling the code that
# wanted it.
#
# `unidic` is absent on purpose too: it installs an EMPTY Japanese dictionary
# directory that mecab then prefers over the bundled unidic-lite, which breaks
# French synthesis at import time. Videofy synthesises no Japanese.
#
# NOT EXPRESSIBLE HERE: the two locally built wheels. pip freeze records them as
# absolute file:// paths containing a home directory, so they are identified in
# engine-sources.json by source commit, wheel filename and SHA-256 instead.
#
# torch/torchaudio are the CUDA 12.8 builds (sm_120 / Blackwell). Install them
# FIRST from the CUDA index, or resolving the rest pulls a CPU build over them.
# Full order is in engine-sources.json.
#
# Python 3.9 (the OpenVoice/MeloTTS dependency floor).
