# Changelog

## v0.1.0-phase1 - Phase 1 Foundation

- Established the mock-only Videofy Live foundation.
- Added React listener and operator applications.
- Added the Node Socket.IO realtime gateway and mock media-ingest service.
- Added the Python mock speech worker.
- Added shared TypeScript event contracts and runtime validation.
- Added language-room routing, ordered translation delivery, duplicate and stale-event rejection, and bounded sequence-gap recovery.
- Added operator health reporting, mock controls, translated-audio queueing, and browser-generated mock video.
- Added local Windows and Unix launchers.
- Added automated CI and a real Python-to-Node cross-process smoke test.
